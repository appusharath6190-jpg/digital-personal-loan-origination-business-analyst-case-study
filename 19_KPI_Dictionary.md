# KPI Dictionary

| KPI | Definition | Formula / interpretation |
|---|---|---|
| Application completion rate | Submitted applications / started applications | Use consistent cohort and time window |
| First-time-right rate | Applications accepted for processing without applicant rework / submitted applications | Exclude policy declines |
| Median decision TAT | Median time from valid submission to decision | Report p50 and p90 by channel / segment |
| Manual review rate | Applications routed to manual review / applications decisioned | Monitor with risk outcomes |
| Exception ageing | Time an exception remains unresolved | Report median, p90 and SLA breaches |
| KYC completion rate | Applications reaching verified KYC / applications requiring KYC | Segment by source and exception |
| Offer acceptance rate | Accepted offers / offers issued | Control for offer expiry |
| Disbursal success rate | Confirmed disbursals / accepted offers eligible for disbursal | Reconcile with downstream source |
| Override rate | Decisions overridden / decisions eligible for override | Segment by role, reason and outcome |
| Early delinquency | Accounts delinquent within a defined early-life window / disbursed accounts | Define DPD window with Risk |
| Complaint rate | Relevant complaints / applications or disbursed accounts | Define complaint taxonomy |

**Guardrail:** Faster processing and higher conversion must not be treated as success if fraud, complaints, policy exceptions or early delinquency deteriorate.
