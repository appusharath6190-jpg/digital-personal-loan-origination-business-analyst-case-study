# Definition of Ready / Definition of Done

## Definition of Ready
- Business outcome and user persona are clear.
- Story is independent enough to estimate and prioritise.
- Acceptance criteria are testable and cover negative / exception paths.
- Data fields, source, consent and access implications are identified.
- Dependencies, API contracts and policy owners are known.
- Compliance, Legal, Risk, Security or Privacy review is identified where required.
- UX copy / wireframe is available where the story changes a customer or staff journey.

## Definition of Done
- Code / configuration completed and peer reviewed.
- Unit, integration and relevant regression tests pass.
- Acceptance criteria demonstrated to Product Owner.
- Security, privacy and audit requirements verified.
- Logs, metrics, alerts and operational runbook updated.
- Error handling, retries and reconciliation tested.
- User / operations documentation updated.
- No open critical defects; residual risks accepted by authorised owner.
- Traceability and release notes updated.
