# SQL Queries and Sample Dataset

The repository also contains `sample_loan_applications.csv` and `loan_analysis_queries.sql`.

## Questions answered
1. How many applications are received by status?
2. What percentage of applications are returned for missing information?
3. What is the average decision turnaround time?
4. Which application channel contributes the most volume?
5. What are the leading recorded decline or exception reasons?

## Data handling
The sample dataset is synthetic and contains no real customer information. The SQL is illustrative and may require minor syntax changes for a specific database engine.

## BA interpretation
A BA uses the outputs to validate process pain points with stakeholders, define KPI calculations, and help product/operations teams prioritise improvements. SQL findings alone do not establish causation or determine creditworthiness.
