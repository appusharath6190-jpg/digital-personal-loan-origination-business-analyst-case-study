# Digital Personal Loan Origination – Business Analyst Case Study

## About this project

I put this case study together to practise how a Business Analyst might approach a personal-loan application journey in a retail bank.

The scenario is a fictional bank that wants to make its loan application process easier to follow, reduce avoidable manual work and give customers clearer updates. The proposed journey covers the application, consent, KYC checks, credit-bureau information, affordability review, decisioning, offer acceptance and the hand-off for disbursal.

This is a simulated portfolio project. It is intended to show the analysis and documentation that can sit behind a BFSI change initiative. It is not a live banking implementation.

## How to review the case study

If you are new to the project, start with the business context and current process (01–05). Then review the proposed process and requirements (06–16). The backlog, KPIs, sample data and UAT material (17–22) show how the requirements could be carried into delivery and validation. Finish with the risk and regulatory notes (23–24).

The documents are examples for discussion and practice. In a real project, a BA would validate the details through stakeholder interviews, workshops, existing process documentation, policy owners and technical teams. The requirements and process would change as those discussions uncover more information.
